# Othello Retro — テストケースと測定結果

オセロの盤面から、標準初期配置を出発点とする合法な棋譜を一つ復元する実験です。元の対局の特定や、最善手の計算を目的としていません。

試験公開アプリ: https://othello-retro.logicpuzzle.app/  
作成された棋譜: https://othello-retro.logicpuzzle.app/examples

このリポジトリでは、まずテスト盤面・参照棋譜・実測結果・使用ソルバーの情報を公開します。実装、実行ファイル、学習済みモデルはライセンスと依存関係の確認中につき含めていません。現時点では、このリポジトリだけから復元プログラムを再実行することはできません。

## データ

- [固定テストケース](benchmarks/cases.json): 到達可能7例、到達不能1例。
- [作成された棋譜](records/created-games.json): 合法手と到達盤面を独立に再生検証した7例。
- [Mac M4 の測定結果](benchmarks/results/local-20261025/report.md): 各方式・各盤面60秒、1回、ローカルCLIによる計測。
- [WSLの測定結果](benchmarks/results/wsl-20261025/report.md): Ryzen 9 9950X、専用4 CPU枠。
- [WSLのモデル読込後の追加測定](benchmarks/results/wsl-warm-20261025/report.md): 読込時間は別に記録、各盤面で新しいモデルを準備。
- [Cloud Runの測定結果](benchmarks/results/cloud-run-20261025/report.md): 4 vCPU / 4 GiB、本番ワーカーをCLIから測定。
- [使用ソルバーと公開範囲](SOLVERS.md)

盤面は a1 から h8 まで行優先の64文字です。X=黒、O=白、-=空。棋譜の座標は同じ向きで、pass は合法手がない側のパスを表します。参照棋譜は到達可能性の証拠であり、唯一解を意味しません。到達不能例は初期配置の中央4マスの一つが空で、石が除去されないという不変条件に違反します。

## 初回測定（2026-10-25）

| 環境 | 方式 | 到達可能の復元 | 到達不能の判定 | 到達可能・成功時中央値 |
|---|---|---:|---:|---:|
| Mac M4 / macOS arm64 | SAT 系 | 7/7 | 1/1 | 17.816秒 |
| Mac M4 / macOS arm64 | 自動（学習誘導＋SAT） | 7/7 | 1/1 | 10.146秒 |
| WSL / Ryzen 9 9950X・4 CPU枠 | SAT 系 | 7/7 | 1/1 | 6.794秒 |
| WSL / Ryzen 9 9950X・4 CPU枠 | 自動（学習誘導＋SAT） | 7/7 | 1/1 | 10.642秒 |
| Cloud Run / 4 vCPU・4 GiB | 自動（学習誘導＋SAT） | 6/7 | 1/1 | 17.162秒 ※ |

SAT 系にも前処理と短時間の直接探索が含まれます。自動方式は学習モデルで候補を絞り、失敗時には元の盤面をSATで探索します。モデルは毎試行新しいプロセスから開始し、OSキャッシュは消していません。Mac側はPyTorch 2.12.1、MPSが利用可能な環境です。時間はローカル処理全体を含み、通信と公開サービスの待ち行列は含みません。小さな固定セット・反復1回の結果なので、一般的な性能の保証やハードウェアだけの優劣の結論には使えません。WSLはCPU推論、MacはMPS対応環境でライブラリ版も異なります。Cloud Runはサービス中のモデルプロセスを再利用しており、cold条件は揃えていません。

※ Cloud Runは7局中1局が60秒以内に復元できずunknownでした。中央値は成功6局のみで、失敗例を除きます。未解決を120秒とした到達可能7局の平均は、Mac自動9.085秒、WSL自動8.852秒、Cloud Run自動30.196秒です。Cloud Runのソルバー秒と、ローカル実行全体の秒には計測境界の差があります。各行の環境メタデータと個別結果を合わせて確認してください。
