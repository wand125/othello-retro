# Othello Retro — テストケースと測定結果

オセロの盤面から、標準初期配置を出発点とする合法な棋譜を一つ復元する実験です。元の対局の特定や、最善手の計算を目的としていません。

試験公開アプリ: https://othello-retro.logicpuzzle.app/  
作成された棋譜: https://othello-retro.logicpuzzle.app/examples

このリポジトリでは、テスト盤面・参照棋譜・実測結果・使用ソルバーの情報を公開します。実装、実行ファイル、学習済みモデルはライセンスと依存関係の確認中につき含めていません。現時点では、このリポジトリだけから復元プログラムを再実行することはできません。

## 測定

[同一盤面・各3回の比較](COMPARISON_3X.md)と[測定条件・照合ハッシュ](benchmarks/protocol-3x.json)を参照してください。CPU比較は同じ固定8盤面、同じモデルとPython探索コード、Torch2.6/NumPy2.2.6、CPU/FP32、推論2スレッド、各60秒に揃えています。モデル読込込みと読込後を分け、中央値・最小・最大、未解決数を記録します。CPUアーキテクチャ・OS・CPU割当は異なり、各環境のメタデータに明記します。

以前の各1回のベンチマークは現行の公開資料から取り下げました。各3回のデータは完了した環境から掲載し、未完了の環境は測定中と示しています。初回のMac測定は実際の推論デバイスを記録していなかったため、MPS実測としては扱いません。

## 検証用データ

- [固定テストケース](benchmarks/cases.json): 到達可能7例、到達不能1例。
- [作成された棋譜](records/created-games.json): 合法手と到達盤面を独立に再生検証した7例。計算時間が付いている場合も、それぞれの棋譜を作成した際の記録であり、環境間の性能比較用の測定ではありません。
- [使用ソルバーと公開範囲](SOLVERS.md)

盤面は a1 から h8 まで行優先の64文字です。X=黒、O=白、-=空。棋譜の座標は同じ向きで、pass は合法手がない側のパスを表します。参照棋譜は到達可能性の証拠であり、唯一解を意味しません。到達不能例は初期配置の中央4マスの一つが空で、石が除去されないという不変条件に違反します。

ケースファイル SHA-256: `292d782cdd23d794e33bc829286a9c0dd4d11979e1db06b27bbf362b0d1a8d64`

## 作成情報と公開範囲

試験公開アプリでは、新規に作成する盤面・棋譜・計算時間などの情報を取得・保存し、作成された棋譜として公開します。過去の利用ジョブを一括公開することはしません。

利用記録、ブラウザ識別子、認証情報、私有インフラ設定は含めていません。プログラムと学習済みモデルの配布条件、および第三者のライセンス表示は確認を継続しています。本リポジトリに実装のオープンソースライセンスを付与したものではありません。
